プライバシーポリシー

Health Meal Log（以下「本ツール」）は、開発者本人だけが使う個人用ツールです。

取得するデータ

本ツールは、Google Health API を通じて、本人の Google アカウントの活動・睡眠・健康指標・栄養・水分のデータを読み取り、本人が撮った写真から推定した食事と水分の記録を書き込みます。

データの使い方と保存場所

データは本人の Mac の中にだけ保存し、本人のための記録と健康レポートの作成にだけ使います。第三者への販売・提供・広告への利用はしません。推定とレポート作成のために、本人が契約している AI サービスにデータを送ることがあります。

削除

本人はいつでも Google アカウントの設定から本ツールのアクセス権を取り消し、Mac に保存したデータを削除できます。

Google API Services User Data Policy

Health Meal Log's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
